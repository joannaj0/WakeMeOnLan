# WakeMeOnLan

A **C#** networking project that scans the local network and displays a list of available devices. It can also wake sleeping devices using Wake-on-LAN (WoL).


## Features

* Scan and list devices on the network
* Display available devices
* Wake sleeping devices using Wake-on-LAN

## How to Run

To check how the project works, you will need a development environment that supports programming in C#.

1. Download the repository to your device and check whether it also contains the database, specifically the BazaWakeMeOnLan.mdf file.
2. Open the project in a development environment that supports C# programming.
3. Start debugging.
